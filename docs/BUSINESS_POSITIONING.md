# Moonworld 사업 포지셔닝

## 핵심 포지션

**Manufacturing Expertise. AI-Driven Innovation.**

Moonworld는 제조 현장의 업무와 기존 정보시스템을 이해하고, 필요한 DX·AI 소프트웨어를 설계·구축하는 기술 파트너로 소개한다. 핵심 메시지는 다음과 같다.

> 제조 현장을 이해하고, AI로 업무를 혁신합니다.

제조 시스템 구축 경험과 ML/DL/LLM 기술을 연결해 스마트공장, 데이터 분석, 생성형 AI, 엔지니어링 자동화의 실제 적용을 돕는다. 제품을 먼저 강조하기보다 고객의 업무 문제와 적용 경계를 먼저 설명한다.

## 주요 고객과 해결하려는 문제

- 중소·중견 제조기업의 경영진과 IT·DX 담당자
- 공장 운영, 생산기술, 품질, 설비 담당자
- 자동차 부품·기계 제조기업의 연구소와 설계부서
- 제조업에 AI를 검토 중인 현업·기술 조직

주요 문제는 흩어진 업무 데이터, 반복적인 수작업, 오래된 시스템의 연계·개선, 현장에 맞지 않는 AI PoC, 기존 CATIA 모델의 구조 파악과 반복 설계 변경이다.

## 제공 영역

1. **Manufacturing DX & Smart Factory** — 제조 정보시스템, 스마트공장, 생산·설비·품질 업무 디지털화, 데이터 연계와 시스템 개선
2. **Industrial AI — ML & Deep Learning** — 제조 데이터 분석, 분석·예측 모델, 기존 업무시스템과의 통합
3. **Generative AI & AI Agents** — LLM/RAG 업무 애플리케이션, 사내 지식 활용, 업무별 Agent와 PoC
4. **Engineering AI & Design Automation** — CATIA V5 기반 설계 변경 지원, 반복 설계 자동화, CAD/PLM 연계 검토

이 영역은 제공 가능한 서비스의 범위로 소개한다. 각 영역의 실제 납품 사례, 성과 지표, 고객 관계는 확인된 근거가 생길 때 별도로 공개한다.

| CATIA Engineering Agent | `ideagpt/261006-EA`는 2026-10-06 기준 MVP 아키텍처·범위 문서다. `catia-mcp`에는 동작 코드와 정확히 한정된 지원 경로, 내부 RC 문서가 있다. 현재 제품 상태는 `CONDITIONAL_GO`, 내부 RC는 제한 사항이 있으며 고객·상업 파일럿은 시작되지 않았다. | `개발 중 · 내부 검증 범위 제한`으로 표기. 모든 모델·기능 지원, 완전 자율 설계를 약속하지 않음 |
| CATIA 변경 업무 AI 기획 | `catia-ai` HEAD의 README, 제품 계획, 파일럿 명세는 변경 검토 패키지 방향과 파일럿 계획을 설명한다. 해당 저장소에는 실행 가능한 제품 코드가 없음 | 기획·연구 방향으로만 표기. Demo/PoC 라벨을 붙이지 않음 |
| Agentic Knowledge Management System | 지정된 저장소에서 검증 가능한 완성 시스템이나 외부 시연물을 확인하지 못함 | 연구 후보로만 소개하거나 제품 목록에서 제외 |
| ML/DL·LLM 고객 구축 실적 | 지정된 자료에서 고객 납품·운영을 입증하는 공개 사례를 확인하지 못함 | 서비스 역량으로 설명하되 납품 사례처럼 말하지 않음 |
| 법적 사업자 정보·브랜드 소유 정보 | 현재 자료만으로 확인 불가 | 상호·주소·등록번호·인증·파트너십을 만들지 않음 |

## 콘텐츠 작성 원칙

- 사용자가 제공한 사업 정의와 저장소에서 확인한 구현·문서 상태를 구분한다.
- 개인 경력과 조직의 실적을 동일시하지 않는다.
- 고객명, 산업 세부정보, 프로젝트 기간, 성과, 파트너십, 인증, 제품 Demo는 공개 승인과 근거를 확인한 뒤 게시한다.
- AI는 기존 업무와 시스템에 적용하는 수단으로 설명하고, 결과를 보장하는 과장 표현은 피한다.
- CATIA 흐름은 `읽기 → 변경 후보 확인 → 계획 검토 → 사용자 승인 → 제한된 변경 실행 → 결과 확인`으로 설명한다.
