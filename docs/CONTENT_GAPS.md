# 콘텐츠 확인이 필요한 항목

아래 항목은 현재 제공된 사업 지시와 지정 저장소만으로 확인되지 않았다. 확인 전에는 웹사이트에 구체적인 사실처럼 게시하지 않는다.

## 문의 접수

- 공식 문의 이메일 `contact@moonworld.uk`는 제공받아 Contact 페이지와 공통 Footer에 적용했다. 버튼은 `mailto:contact@moonworld.uk`를 열며 DNS와 Cloudflare Email Routing 설정은 변경하지 않았다.
- 별도 문의 양식이나 웹 전송 서비스는 구현하지 않았다. 사용자가 이메일 앱에서 직접 작성·전송한다.
1. 문의를 확인하는 담당자와 회신 기대 시간을 어떻게 안내할 것인가?
2. 법적 사업자·개인정보 처리 주체를 확인할 자료와 개인정보 처리방침 공개 위치는 무엇인가? (추후 웹 양식을 도입할 경우 게시 전에 확정)

## 회사와 브랜드

1. MOONWORLD는 법인/개인 사업자의 상호인가, 서비스 브랜드인가?
2. 푸터에 공개할 법적 사업자명, 등록번호, 대표자, 사업장 주소, 전화번호가 있는가?
3. 공개 가능한 조직 소개·설립 정보·운영 지역이 있는가?
4. MOONWORLD 워드마크와 도메인·상표를 사용할 권한 및 브랜드 가이드가 확인되었는가?

## 구축 경험과 고객 공개 승인

각 프로젝트별로 다음을 제공해야 한다.

- 프로젝트 분야와 고객 산업
- 고객 실명 공개 또는 익명화 승인
- 해결 대상과 당시 업무 방식
- Moonworld의 정확한 역할과 수행 범위
- 시스템명·기술·연계 환경과 사용 권한
- 결과물과 운영 상태
- 성과 수치의 산식·기간·근거 자료
- 이미지·화면·로고의 공개 권한
- 게시 담당자의 고객 승인 기록

사용자의 개인 경력, 이전 소속 조직의 실적, 협력사의 실적은 Moonworld의 수행 실적으로 자동 기재하지 않는다.

## 제품·R&D 상태

1. `catia-mcp`의 현재 내부 RC에서 외부 시연 가능한 정확한 범위와 설치·환경 제약은 무엇인가?
2. CATIA Engineering Agent를 외부에 `Prototype/PoC`로 공개해도 되는 승인된 데모 영상·스크린샷·테스트 결과가 있는가?
3. CATIA Engineering Agent의 최신 내부 지원 경로, 알려진 제한, 제품 명칭·배포 정책은 무엇인가?
4. Agentic Knowledge Management System은 연구 제안, 실행 중 프로토타입, PoC 중 어느 단계인가? 공개 가능한 코드·시연·평가가 있는가?
5. 제조 AI 분석·예측 소프트웨어에 구현 코드·데이터·검증 결과가 있는가?
6. 제품별 고객 데이터 사용 권한, CATIA 및 제3자 소프트웨어·자료 표시 조건은 무엇인가?

현재 조사에서 확인한 `catia-mcp` HEAD 문서는 `CONDITIONAL_GO`, 내부 RC 제한 사항, 고객·상업 파일럿 `DEFERRED / NOT_STARTED`를 기록한다. `catia-ai` 저장소는 제품·파일럿 기획 문서이며 실행 제품 코드를 포함하지 않는다. 해당 상태를 바꾸려면 최신 승인된 증거가 필요하다.

## 서비스 운영 범위

1. 실제 계약·수행 가능한 서비스 범위와 제외 범위는 무엇인가?
2. 제조 시스템 구축에서 실제 제공 가능한 플랫폼·기술 스택과 협력사 관계는 무엇인가?
3. 고객 공장 데이터의 반출·보관·접근 통제 정책은 무엇인가?
4. PoC의 기간·비용·입력 데이터·성공 판정 기준을 어떻게 정의하는가?
5. 유지보수·SLA·현장 방문·운영 지원 제공 여부는 무엇인가?

## 공개 전 점검

- 고객명, 브랜드 로고, 제품 UI, 데이터, 모델 파일의 공개 승인
- 성과 수치의 원본 근거와 산식
- 제품 상태와 현재 코드 기준의 일치 여부
- 법적 사업자·개인정보·저작권 안내
- 공식 이메일 링크의 표시와 `mailto:` 대상 확인
