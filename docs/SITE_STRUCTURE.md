# Moonworld 홈페이지 구조

## 사이트 목표

방문자가 Moonworld의 제조업 이해, 해결 가능한 업무, 현재 확인 가능한 구현 수준, 프로젝트 시작 절차를 파악하고 상담을 검토하도록 돕는다. 기본 언어는 한국어이며, 영문 문구는 브랜드 메시지와 기술 영역명에 제한한다.

## 내비게이션

홈 · 솔루션 · 구축 경험 · 제품·연구 · 서비스 · 회사 소개 · 문의

주요 CTA는 **프로젝트 상담하기**다. 모든 주요 페이지에서 문의 페이지로 이동할 수 있다.

## 공통 화면 구성

- `BaseLayout`: 한국어 문서 언어, title/description, canonical, Open Graph 기본 메타, favicon, 공통 CSS.
- `Header`: 워드마크, 주요 내비게이션, 모바일 메뉴, 상담 CTA.
- `Footer`: 사이트 링크, 브랜드명, 공식 문의 이메일 `contact@moonworld.uk`.
- `PageHero`: 각 서브페이지 제목과 간결한 설명.
- `SolutionCard`: 데이터 기반 사업 영역 링크 카드.
- `StatusLabel`: 개발 중, 기획·연구 등 정확한 제품 상태.
- `CTASection`: Contact 페이지로 연결하며, Contact 페이지에서 확인된 공식 이메일 문의 경로를 안내.

## 디자인 원칙

- Navy `#0B1730`, white `#FFFFFF`, blue `#2563EB`, 차분한 회색 선을 기본으로 한다.
- 제조 현장 이미지는 맥락을 전달하는 곳에만 사용한다. 제품 화면은 코드 기반 구조도·작업 흐름으로 설명한다.
- 수치, 고객사 로고, 수상·인증, 임의의 후기와 가짜 소프트웨어 대시보드는 사용하지 않는다.
- 넓은 화면은 편집형 그리드와 여백을 활용하고, 모바일은 한 열로 단순화한다.
- 움직임은 메뉴 열기와 포커스 상태 등 명확한 사용성에 필요한 수준으로 제한한다.

## 기술 구성

- Astro 파일 기반 정적 라우트와 Astro 컴포넌트를 사용한다.
- 공통 데이터는 `src/data/`의 TypeScript 객체로 관리해 사례와 제품을 검증 후 추가한다.
- 글로벌 디자인 토큰과 반응형 규칙은 `src/styles/global.css`에서 관리한다.
- sitemap과 robots 정책은 정적 파일로 제공한다.
- 공식 문의 버튼은 `mailto:contact@moonworld.uk`를 연다. 웹 문의 양식이나 별도 전송 서비스는 구현하지 않는다.
- `astro.config.mjs`, `wrangler.jsonc`, GitHub 및 Cloudflare 설정을 변경하지 않는다.
